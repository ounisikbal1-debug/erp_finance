# Transactions intercompagnies

Le module `/api/intercompany` et le panneau **Transactions intercompagnies** créent une opération de vente/achat liée entre deux entités du même groupe. SAFE génère les deux écritures équilibrées dans leurs devises fonctionnelles et conserve la référence, les comptes, les montants, la devise et le taux utilisé.

Le cycle est atomique pour la paire : création des deux pièces en revue, approbation par une autre identité, comptabilisation par une troisième identité, puis rapprochement confirmé séparément par chaque entité. Les actions habituelles de validation, de rejet, de comptabilisation ou de contrepassation d’une écriture individuelle sont bloquées pour empêcher de désynchroniser la paire.

Ce premier périmètre couvre une vente de marchandises sans calcul automatique de TVA, taxes, règlement, intérêts, prix de transfert ou élimination de consolidation. La devise de transaction doit être celle du vendeur; le taux indiqué exprime la devise fonctionnelle acheteur par unité de devise vendeur. Les règles et taux de démonstration sont fictifs et ne constituent pas une conformité comptable ou fiscale.

Les appels principaux sont `GET /api/intercompany/partners`, `GET /api/intercompany/transactions`, `POST /api/intercompany/transactions`, puis les actions `/approve`, `/post` et `/reconcile` sur une transaction. Les contreparties proposées sont les autres entités membres d’un groupe commun.

Pour associer les quatre anciennes paires d’écritures fictives de la base de démonstration au modèle natif et créer 26 opérations supplémentaires, déployer d’abord le schéma dans la base dédiée `dashboard-demo-synthetic.db`, puis exécuter `npm run demo:dashboard:intercompany` avec `SAFE_ERP_DATABASE_URL=file:../dashboard-demo-synthetic.db` et `SAFE_ERP_DASHBOARD_DEMO_CONFIRM=YES`. Le jeu livré contient ainsi 30 opérations sur 12 paires de devises/sociétés; les 26 nouvelles passent par le workflow natif avec un cycle préparateur/contrôleur/comptabilisateur, tandis que les quatre opérations historiques sont comptabilisées et rapprochées des deux côtés. L’export `SAFE-Tableau-Financier-EXEMPLE-SYNTHETIQUE-COMPLET.xlsx` inclut une feuille Transactions interco avec les entités, devises, taux, montants, références des pièces et confirmations. Tous les taux sont purement synthétiques; le script refuse les autres cibles et ne modifie que les écritures fictives identifiées.
